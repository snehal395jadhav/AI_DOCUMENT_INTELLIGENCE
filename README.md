# Overview

**PrePressAI Neural Studio** is an enterprise AI-powered prepress intelligence platform designed to automate the analysis, separation, validation, quality control, and production preparation of professional print artwork.

The platform combines:

- Artificial Intelligence
- Computer Vision
- YOLO Segmentation
- Vision-Language Models
- OCR
- PDF Intelligence
- Measurement Extraction
- Geometry Analysis
- AI Risk Scoring
- Production Export Automation

PrePressAI transforms traditional manual prepress inspection into an intelligent AI-assisted workflow capable of detecting technical artwork components, analyzing production quality, identifying potential risks, and preparing structured production outputs.

The platform is designed for publishing, packaging, printing, artwork production, prepress engineering, and enterprise quality-control workflows.

# Docker Entrypoint

The startup script:

```text
docker-entrypoint.sh
```

automatically:

```text
Creates /app/.streamlit

        │
        ▼

Checks OPENROUTER_API_KEY

        │
        ▼

Creates secrets.toml

        │
        ▼

Starts Streamlit

        │
        ▼

0.0.0.0:8502
```

The application runs in headless Streamlit mode.

---

# Docker Compose

Build and start:

```bash
docker compose up --build
```

Run in background:

```bash
docker compose up -d --build
```

Stop:

```bash
docker compose down
```

View logs:

```bash
docker compose logs -f
```

# Docker Restart Policy

The Compose configuration uses:

```yaml
restart: unless-stopped
```

This allows the application container to restart automatically unless it is explicitly stopped.
